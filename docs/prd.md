- 用 chrome 插件作为分布式爬虫，分布式 AI 翻译，用户在本地爬虫，在本地翻译，最后同步到服务器。
- proxy，就是不同地方的爬虫，不管是国内外的服务器，还是浏览器，都可以作为爬虫，都可以作为最终的数据源。
- NewsNext 预见趋势。中文名就可以叫预见。
- 直接把网页内的一部分作为小组件。
- NewsNext, Read First.
- cache 怎么做，单条存储只有 timeline 能用，排行榜类的就不行。那区分开吗。
- 单条存储的好处，一是持续存储，比如可以记录一天的新闻。二是方便搜索，方便翻译。但是有时候，同一个链接里的评论或者热度，会发生变化，不过本来也是分开存储的，同一个链接可以更新。
- 但是比较麻烦的就是排行榜类的，因为排名没法通用，用户想看的就是当时的排名，而不需要一个统一的排名。我怎么存储呢。
